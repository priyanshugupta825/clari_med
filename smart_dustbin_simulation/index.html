Key Working Principles:

  1. Touch-free Lid: When user approaches hand, the IR sensor detects reflection and triggers the SG90 servo motor to rotate 90°, opening the lid. After 3 seconds without hand detection, the lid automatically closes.
  2. Garbage Level Sensing: HC-SR04 ultrasonic sensor emits 40 kHz pulses, calculates echo travel time, and computes fill % = ((Bin_Height - Distance) / Bin_Height) * 100.
  3. Threshold Alerting: When fill level reaches or exceeds the threshold (85%), NodeMCU sounds the local buzzer, blinks the red LED, and transmits a real-time Wi-Fi alert to the IoT cloud dashboard.
